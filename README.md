# 育成シミュレーション

オリジナルキャラクターを育てるミニマムな育成シミュレーションゲーム（プロトタイプ）。
フロントエンドのみで完結し、セーブデータは localStorage に保存されます。

## 遊び方

1. `npm install`
2. `npm run dev`
3. ブラウザで表示されたURLを開く

キャラクターを作成し、12ターンの間「トレーニング」「休養」「お出かけ」を選んで育成します。
6ターン目に中間試験、12ターン目に最終評価（S/A/B/C/D）があります。

## 技術スタック

- React + TypeScript + Vite
- Tailwind CSS
- localStorage によるセーブ/ロード

## ディレクトリ構成

- `src/types.ts` — ゲーム内の型定義
- `src/data/` — トレーニング・イベントのマスターデータ
- `src/game/` — ゲームロジック（reducer, ランク計算, セーブ処理）
- `src/components/` — 画面コンポーネント
